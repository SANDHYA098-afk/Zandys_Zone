# 01. PORTFOLIO IDENTITY

## Name

# 02. CORE EXPERIENCE DIRECTION

## Main Concept

The entire portfolio should feel like a **personal video game / interactive digital world**.

This is NOT a conventional portfolio with a game-themed color palette.

The **entire user journey** should feel gamified:

- Loading screen
- Navigation
- Hero
- About
- Skills
- Experience
- Projects
- Achievements
- Certifications
- Art
- Social/contact
- Transitions
- Footer/end state

Every part should contribute to the same game-like universe.

## Core feeling

The visitor should feel like they have entered:

> **Zandy's Zone — a small playable/explorable universe containing my work, skills, experiences, achievements and art.**

The portfolio should be:

- Interactive
- Animated
- Playful
- Futuristic
- Space-themed
- Gamified
- Personal
- Recruiter-friendly
- Readable
- Fast enough to remain practical

The gamification must enhance the portfolio rather than make it difficult to use.

# 03. VISUAL THEME

## Color Direction

Use a **space-inspired color palette**.

Possible visual ingredients:

- Deep space / near-black backgrounds
- Dark navy / midnight blue
- Cosmic purple
- Neon blue
- Neon violet
- Subtle pink/magenta accents where useful
- White/light text for readability
- Small glowing highlights

The final palette should feel like:

> **deep space + futuristic game interface**

Avoid making every element glow heavily.

The interface should have a hierarchy:

- Dark environment
- Bright interactive elements
- Subtle stars/particles
- Controlled neon highlights
- Strong contrast for readable text

## Visual Atmosphere

Possible visual elements:

- Stars
- Nebula-like gradients
- Small planets
- Orbits
- Constellation lines
- Holographic panels
- Game HUD elements
- Mission markers
- Coordinates
- XP/badge-inspired elements
- Sci-fi interface details
- Subtle particle movement

These should support the experience without overwhelming the content.

# 05. LOADING SCREEN

## Concept

The loading screen must have a short animated story.

### Required animation

A **UFO appears/flys in**.

Then:

> **Someone/character falls down from the UFO.**

The character lands.

Then the loading completes and the portfolio/game world opens.

Conceptually:

```text
          🛸
        UFO
         ↓
     character
         ↓
      falls
         ↓
       lands
         ↓
   LOADING COMPLETE
         ↓
      GAME MENU
```

The exact character design can be decided later.

## Character

Preferred:

- An animated character
- Space/adventure/game-like appearance

The character may be:

1. A supplied image/asset provided later
2. A custom animated character created through CSS/SVG/code
3. Another lightweight visual solution

The animation should be lightweight enough not to make the initial load unnecessarily slow.

## Loading UI

Possible supporting elements:

- Loading percentage
- "Entering Zandy's Zone..."
- Small system messages
- Progress indicator
- Stars/particles

Do not make the loading screen excessively long.
